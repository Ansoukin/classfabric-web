ClassFabric 是什么

ClassFabric 是基于 HelloWRC 的 ClassIsland 二次开发的个人修改版。在保持积极同步上游最新特性的同时，融入来自个人与社区的修改，例如多语言、云功能、更好的自动化、更好的性能表现与更多功能。

其中一部分已经完成，另一部分仍处于规划阶段，详见下文「已经做了」与「计划中」。

与 ClassIsland 的关系

ClassFabric 不是 ClassIsland 的完美替代品，也不是它的竞品，而是在其基础上二次开发的版本。ClassIsland 的作者是 HelloWRC；ClassFabric 沿用上游的 GPL-3.0 开源协议，软件的「关于」页中也保留了上游的版权声明。

从 ClassIsland 切换，需要做什么

不需要复杂的前期工作。ClassFabric 的底层代码与上游保持一致，只需下载并安装，原有的课表、自动化、插件与主题即可接着使用。

我们正在把底层代码尽量还原到与上游一致，同时保持界面中显示的名称为 ClassFabric，目的就是让切换对你「无感」。

适合谁，不适合谁

适合：想在 ClassIsland 生态上保持现有内容，又希望及时体验上游新功能的人；以及希望开箱即用，装完就能体验上游、社区与我们开发的各类新功能的人。

不太适合：希望环境长期保持不变的人，或对稳定性有极高要求的场合。ClassFabric 会积极同步上游的更改，版本变化相对频繁。

已经做了什么

  • 紧跟上游：同步 ClassIsland 的新功能与修复。
  • 更多天气源：除小米天气外，新增 OpenWeather 与和风天气。
  • 多语言（实验中）：ClassIsland 的界面文字原本是写死的，我们已将其中大部分改为可翻译的形式，目前支持简体中文、繁體中文与 English，约完成 40%。仍有不少文字与界面需要适配，欢迎在 Crowdin 上参与翻译。
  • 更好的插件预览：插件市场的详情页可预览更多内容。

想了解具体改动，可以查看 GitHub 提交记录。

计划中

以下内容仍在规划阶段，尚未可用。

云功能 · 远程提醒

从远端向大屏发送提醒。

云功能 · 集中管理

统一管理多台设备。上游暂未提供，社区项目 ClassislandControlHub 正在积极开发。

云功能 · 云端备份

通过 SFTP、WebDAV、OpenList 等方式备份档案与配置。

更好的自动化

主要借助社区知名插件 SystemTools 实现。

更好的性能表现

持续优化。

名字由来

ClassIsland 的 Island，来自 iOS 的「灵动岛」。ClassFabric 的 Fabric，则来自 Minecraft 社区知名的模组加载器 Fabric，寓意将社区与个人的功能连接起来。

参与贡献

欢迎任何有价值的贡献：在 GitHub 提交 Issue 或 PR 即可。我们也会考虑定期将有意义的改动提交给上游，一起建设 ClassIsland 生态。

GitHub 仓库反馈问题

常见问题

支持 Linux 和 macOS 吗？

目前仅提供 Windows 版本。代码中保留了相关支持，但我们暂无测试环境与精力维护，因此暂不提供官方构建。

有交流群吗？

暂时没有。ClassIsland 现有的 QQ 频道与群属于上游项目，ClassFabric 的问题请直接在 GitHub 提交 Issue。

软件出现问题怎么办？

可以先尝试内置的恢复模式：以安全模式启动、查看日志、恢复备份，必要时重置配置。仍无法解决，请在 GitHub 提交 Issue 并附上诊断信息。

它会取代 ClassIsland 吗？

不会。ClassFabric 建立在 ClassIsland 之上，没有上游就没有它。可以把它看作一个「更早体验新功能，并带有额外改进」的选择。

开源协议是什么？

GPL-3.0，与上游一致。ClassIsland 的版权归 HelloWRC，ClassFabric 的改动版权归各自贡献者。
